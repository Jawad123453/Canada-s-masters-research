## Coordinator observations (23 Oct 2026)
- Nunavut Arctic College: no row on the DLI list at all -> cannot host study-permit students. Excluded.
- The King’s University (AB), Burman (AB), St. Mary’s University (Calgary): public, PGWP "Yes", but Grad Program "No" (no PAL-exempt master's).
- Ambrose, Redeemer, Tyndale: private, PGWP "Details" (only some programs). Canadian Mennonite University, Crandall, Kingswood: private, PGWP "Yes". None has Grad Program "Yes". Private institutions -> the user asked to exclude private colleges; treat as excluded unless a master's is confirmed PGWP-eligible on the institution's "Details".
- Université de l'Ontario français: public, PGWP Yes, Grad Program "No".
- Université de Saint-Boniface, Université Sainte-Anne, Université de Hearst, Mount Allison, St. Thomas University, University of King's College, Yukon University, Concordia University of Edmonton, Algoma (all 3 campuses), Guelph, UPEI, VIU, Regina: public, PGWP Yes, Grad Program Yes.
